# 安徽步点智能科技有限公司 - 官方企业级门户官网 (Budian Official Website)

本项目为**安徽步点智能科技有限公司**纯前端工业级官方门户网站，采用**高级明亮浅色设计系统（True Light & Precision Typography）**，基于企业实际资质背景与旗舰产品业务定制开发。

---

## 一、视觉设计定位：高级纯净浅色体系

与传统沉重暗黑界面不同，本版本遵循**腾讯官网（Tencent.com）**与**七牛云（Qiniu.com）**高雅、通透、纯净白底的设计哲学：

- **主底色与卡片**：纯白底色（`#FFFFFF`）搭配极浅的淡冷灰（`#F8FAFC` / `#F1F5F9`）背景块，自然划分内容模块。
- **高对比文字梯度**：
  - 核心强标题：深度石板黑 `#0F172A`
  - 舒适正文：石板深灰 `#334155`
  - 辅助说明：品质石板灰 `#64748B`
- **Logo 专属能量高光**：
  - 提取 3D 无限极 Logo 的活力琥珀橙与电光洋红：`linear-gradient(135deg, #FF5E1E 0%, #FF007A 55%, #7928CA 100%)`
  - 在纯净白底衬托下格外鲜活，极富现代科技与创作活力。
- **精工细作的边框与阴影**：
  - 精致微边框 `#E2E8F0`，配合多阶软阴影（`0 4px 20px -2px rgba(15, 23, 42, 0.06)`），呈现现代云端 SaaS 的立体层次感。

---

## 二、技术栈选型

- **架构标准**：现代高标准原生 Web 架构（Semantic HTML5 + CSS3 Custom Properties Tokens + Vanilla ES2024）。
- **零构建/零后端依赖**：无须配置 Node.js 环境或运行 npm run build，双击 `index.html` 即可在本地或移动端完整呈现。
- **双轨容灾机制**：包含本地高清相对路径与 Data URI 内联兜底，杜绝离线或单文件拷贝导致的破图问题。
